STEP 92b: BLAST TAXONOMY SPECIES LOOKUP CORRECTION
============================================================

BUG DESCRIPTION
----------------------------------------
STEP92 ref_lookup used versioned accession keys (e.g. PX979534.1)
but lookup code normalized BLAST hits to root accessions (e.g. PX979534).
Species lookup failed silently. Taxonomy_agreement defaulted to True.

FIX APPLIED
----------------------------------------
1. Built ref_lookup with root accession keys
2. Extracted Hit_species from Subject_accession 3rd pipe field
   (PX979534.1|NCBI_REF|Aeromonas_caviae -> Aeromonas caviae)
3. Re-classified taxonomy agreement into 4 categories
